# 海ログ（SeaLog）

スマートフォン向けの写真・釣り記録Webアプリです。

## 起動方法（いちばん簡単）
1. ZIPを解凍します。
2. `index.html` をHTTPS対応のWebサーバーに配置します。
3. iPhone/AndroidのSafari/ChromeでURLを開きます。
4. 「ホーム画面に追加」を選ぶとアプリのように使えます。

## ローカルで試す場合
PCにPython 3がある場合、フォルダ内で次を実行します。
`python -m http.server 8000`
同じWi-Fiのスマホからは `http://PCのIPアドレス:8000` で開けます。
ただし、位置情報はHTTPSまたはlocalhostが必要なブラウザが多いため、実運用はHTTPSを推奨します。

## 機能
- 写真プレビュー
- EXIFから撮影日時・GPSを読み込み（EXIFが残っている場合）
- 現在地取得、地図表示、逆ジオコーディング
- Open-Meteo Archive APIで撮影時刻付近の過去天候を取得
- WorldTides APIで潮位・満干潮を取得（APIキー任意）
- IndexedDBに写真と記録を端末内保存
- CSV出力

## 潮汐APIについて
WorldTides APIキーは https://www.worldtides.info/developer/apikey で確認してください。
APIキーなしでもアプリは利用でき、潮回り・潮位を手入力できます。
WorldTidesの利用料金・クレジット・利用条件、表示が必要な著作権表記を確認してください。
APIキーをブラウザに保存する方式は個人利用向けです。複数人に公開する場合は、APIキーをサーバー側に置く構成へ変更してください。

## 注意事項・制限
- 写真のGPS/日時はEXIFが残っている場合のみ自動取得できます。SNS経由の画像やスクリーンショットでは消えていることがあります。
- 写真の撮影日時はカメラの時計設定に依存します。
- Open-Meteoの過去天候は再解析データであり、現地の観測値ではありません。海上・沖合では推定誤差があります。
- 潮汐予測は地点・海域・基準面に依存します。釣行判断や航行の安全には、海上保安庁・気象庁・現地の公式情報も確認してください。
- 地図はOpenStreetMapを利用します。各サービスの利用条件・アクセス制限に従ってください。
- 写真・位置情報は個人情報や釣り場情報を含む場合があります。共有前に位置情報を確認してください。
- 保存データは利用中のブラウザ内にあります。ブラウザのデータ削除、端末故障、別端末への変更で失われる可能性があります。CSVには写真画像は含まれません。

## 使用ライブラリ・データ
- exifr（EXIF解析）
- Leaflet / OpenStreetMap（地図）
- Open-Meteo Historical Weather API
- WorldTides API（任意）
